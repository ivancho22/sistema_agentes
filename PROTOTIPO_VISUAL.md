# Diseño de Interfaz Visual para la Calculadora Inteligente de Paneles Solares

## 1. Paleta de Colores e Identidad Visual
Para el diseño de la interfaz de la calculadora inteligente, sugiero una paleta de colores que refleje sostenibilidad, tecnología y confianza. Aquí está la propuesta:

- **Colores Primarios**:
  - Verde (#4CAF50): Representa la sostenibilidad y la energía renovable.
  - Azul (#2196F3): Simboliza la tecnología y la confianza.

- **Colores Secundarios**:
  - Amarillo (#FFEB3B): Para resaltar información importante y botones de acción.
  - Gris Claro (#F5F5F5): Como fondo neutro que permite que otros elementos resalten.

- **Tipografía**:
  - **Fuente Principal**: Roboto (para un aspecto moderno y legible).
  - **Fuente Secundaria**: Open Sans (para subtítulos y descripciones).

## 2. Mapa de Pantallas del Cliente

### Pantalla de Inicio / Dashboard
La pantalla de inicio debe ser intuitiva y permitir al usuario acceder rápidamente a las funcionalidades principales.

- **Componentes Visuales**:
  - **Encabezado**:
    - Logo de la empresa a la izquierda.
    - Menú de navegación a la derecha (Inicio, Propuestas, Configuración, Ayuda).
  
- **Cuerpo**:
  - **Tarjeta de Bienvenida**: Un mensaje de bienvenida con un botón "Comenzar".
  - **Gráfica de Consumo Energético**: Gráfica de barras que muestra el consumo mensual del usuario.
  - **Botón "Calcular Paneles"**: Un botón prominente en el centro que lleva a la pantalla del core funcional.
  - **Sección de Propuestas Generadas**: Lista de propuestas anteriores con botones para ver, editar o eliminar.

### Pantalla del Core Funcional
Esta pantalla es donde los usuarios ingresan datos para calcular la cantidad de paneles solares necesarios.

- **Componentes Visuales**:
  - **Formulario de Entrada**:
    - Campos para ingresar datos: 
      - Consumo mensual (kWh).
      - Ubicación (con un selector de mapa o campo de texto).
      - Orientación del tejado (opciones de selección).
      - Presupuesto estimado.
  - **Botón "Calcular"**: Un botón destacado para iniciar el cálculo.
  
- **Resultados**:
  - Una sección que muestra el número recomendado de paneles solares.
  - Gráfica de ahorro estimado a lo largo del tiempo.
  - Botón "Generar Propuesta en PDF": Para crear un documento comercial automáticamente.

## 3. Flujo de Navegación del Usuario
A continuación, se describe el flujo de navegación desde que el usuario abre la aplicación:

1. **Pantalla de Inicio**:
   - El usuario ve el logo, menú de navegación y un botón "Comenzar".
   - Al hacer clic en "Comenzar", se redirige a la pantalla del Core Funcional.

2. **Pantalla del Core Funcional**:
   - El usuario completa el formulario de entrada con datos relevantes (consumo, ubicación, etc.).
   - Al hacer clic en "Calcular", el sistema procesa la información y muestra los resultados.

3. **Resultados**:
   - El usuario revisa el número de paneles recomendados y el ahorro estimado.
   - Si está satisfecho, hace clic en "Generar Propuesta en PDF".

4. **Propuesta Generada**:
   - Se muestra un mensaje de confirmación y una opción para descargar el PDF.
   - El usuario puede regresar al Dashboard o crear una nueva propuesta.

5. **Navegación Adicional**:
   - Desde cualquier pantalla, el usuario puede acceder al menú de navegación para ver propuestas anteriores, ajustar configuraciones o acceder a la ayuda.

Este diseño busca ofrecer una experiencia fluida y eficiente para los instaladores y administradores de paneles solares, facilitando el proceso de cálculo y generación de propuestas comerciales.
